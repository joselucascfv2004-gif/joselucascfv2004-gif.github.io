# Créditos e licenças

Skill escrita em português para o José Lucas (31/10/2026). O texto e os scripts são próprios; o **método** vem de:

- **TradingAgents** — Tauric Research, Apache License 2.0 — https://github.com/TauricResearch/TradingAgents (versão
  v0.7.1, 27/10/2026). Artigo: "TradingAgents: Multi-Agents LLM Financial Trading Framework", arXiv 2412.20138. Daqui
  vêm os papéis (analistas, debate otimista × pessimista, gerente de pesquisa, operador, equipe de risco, gestor), a
  escala de 5 notas com "REVISAR" quando não há decisão legível, a regra de que discordância não é motivo para "Manter",
  a memória de decisões e a integridade de "ponto no tempo". Os papéis em `referencias/papeis.md` são traduções
  adaptadas dos prompts de `tradingagents/agents/`.
- **anthropics/financial-services** — Apache License 2.0 — ideias de `thesis-tracker`, `catalyst-calendar`,
  `dcf-model` (tabela de sensibilidade com número ímpar de linhas e caso base no centro) e `comps-analysis`.
- **tradermonty/claude-trading-skills** — MIT — ideias de `position-sizer`, `pre-trade-discipline-gate` e
  `signal-postmortem`.
- **himself65/finance-skills** — MIT — uso do `yfinance` como fonte gratuita (`yfinance-data`).

Nenhum código desses projetos foi copiado; nada aqui é afiliado a eles.
